Explain dynamic programming and when to use memoization over tabulation.
AI
Dynamic programming is an algorithmic technique that solves complex problems by breaking them into overlapping subproblems, storing results to avoid redundant computation.

Memoization (top-down): Use when you only need to solve a subset of subproblems. Implemented recursively with a cache. Natural when the problem structure is recursive.

Tabulation (bottom-up): Use when you need all subproblem solutions. Iterative, avoids recursion overhead. Better for space optimization using rolling arrays.
